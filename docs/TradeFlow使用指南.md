# TradeFlow 外贸业务平台使用指南

## 推荐使用顺序

1. 在“产品素材”中新建产品，填写型号、规格、价格与币种。
2. 在“业务单据”中保存公司抬头、联系方式和银行信息。
3. 在“客户与线索”中检索公开客户，或输入官网建立客户档案。
4. 点击“新增商机”，填写客户、产品和预计金额。
5. 在“商机漏斗”中推进询盘、联系、报价、寄样、谈判和成交阶段。
6. 成交后进入“业务单据”，制作 PI、CI 或 PL，并打印为 PDF。
7. 在“行业情报”中查看每天自动更新的市场、产品、渠道、物流与合规资讯。

## GitHub 版本的数据说明

- 客户、产品、商机、公司抬头和单据保存在当前浏览器中。
- 换电脑、换浏览器或清理浏览器数据后，原数据不会自动出现。
- 公开网页不会把你录入的客户资料提交到 GitHub。
- 建议定期使用各模块的导出功能保存备份。

## PI、CI、PL

- PI：形式发票，用于报价确认和收款信息。
- CI：商业发票，用于成交后的商业结算与报关资料。
- PL：装箱单，应填写箱号、箱数、每箱数量、净重、毛重、尺寸、唛头和备注。
- 可切换公司抬头；保存后再次制作单据时可直接选择。
- 完成后使用浏览器打印功能，选择“另存为 PDF”。

## 行业情报

- 系统通过 GitHub Actions 每天自动读取公开 RSS 新闻。
- 默认关注手机与消费电子、市场渠道、物流供应链和法规合规。
- 点击新闻标题可进入原始来源页面。
- 行业情报独立于客户档案，即使没有客户资料也会更新。

## 常见问题

### 页面打开后数据为空

GitHub 版本的数据按浏览器分别保存。请确认使用的是之前录入数据的同一台电脑和同一浏览器。

### 如何备份

优先使用客户、产品和单据模块中的 CSV、打印或导出功能。重要单据建议同时保存 PDF。

### 客户检索为什么会打开搜索网站

GitHub Pages 是静态网站，不能在后台抓取第三方网页。系统会生成公开搜索入口，找到目标公司后可把官网复制回来存档。
